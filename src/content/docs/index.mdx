## Keep a reference while the order changes

The first `push` allocates storage for the pending orders. `&orders[0].number` takes a reference to the first order’s number. Adding an item changes the total and leaves the number in place, so the reference still works.

Adding the next order can move the list’s backing array. Put that `push` before `println!` and the compiler points to the call and the later use of the now-invalid reference.

## Use C and C++ libraries as they are

Point the project manifest at a library’s headers and sources or its CMake build. Use the functions and classes directly from Dazzle. Debuggers and profilers can map generated C++ back to your `.dz` files. [C and C++ interop](/tour/cpp-interop/)

## Install

On Linux or macOS:

```bash
curl -fsSL https://dazzle-lang.github.io/install.sh | sh
```

On Windows, in PowerShell:

```powershell
irm https://dazzle-lang.github.io/install.ps1 | iex
```

Then run `dz new hello`, `cd hello`, and `dz run`. [Installation and compiler requirements](/start/install/)
